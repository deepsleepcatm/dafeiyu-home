# 06-docs · 安装文档

## 里面有什么

| 文件 | 给谁看 |
|---|---|
| `装机清单.md` | **给人看的**：装什么、多大体积、有什么坑 |
| `总览.md` | **一份看全**：A/B 两层、三档怎么选、IM 能力对照（微信 QQ 能做什么不能做什么）、B 档六块 |
| `一键指令.md` | **给对方的 AI 读的**：A 档（只用现成插件） |
| `B档一键指令.md` | **给对方的 AI 读的**：B 档（加自研模块） |

## 怎么用

**推荐流程**：

1. 人先读 `装机清单.md`，知道要装什么、多大、有什么坑
2. 把 `一键指令.md`（A 档）或 `B档一键指令.md`（B 档）整段复制，粘给对方刚装好的 DSH
3. 对方的 AI 装完会给你一份三块清单：已能用 / 还要你做 / 装不上+为什么
4. **你只需要看第二块**，照着做几步

## 设计要点

**指令里最关键的是最后一步**：要求对方的 AI 输出三块清单，而且"还要你做"那块必须写清「在哪做、点几下、准备什么」。

这样你就不用手读安装文档、不用查报错 —— 只看它给你的待办。

## 需要注意

**B 档有三样必须用户自己动手**：宪章要重写、群聊组名自己定、任何要 API key 的地方。AI 替不了。
