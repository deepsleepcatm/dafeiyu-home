# 大肥鱼 · 新手向 DSH 一键部署

**给第一次打开 DSH、看到冰冷冷界面就懵的人。**

很多人装完 DSH 是这样的：界面是空的，什么都不会，然后跑到 B 站、小红书、GitHub、群里到处搜插件。搜一堆回来，装这个跟那个冲突，装那个又报错，**搜着搜着把自己干崩溃了，最后干脆不用了**。

我也经历过。所以这个仓库是我从自己的经验里一样一样试出来、留下能用的，攒成的一个组合。

**你不用再一个个搜。把下面那段话输进去，你的 AI 会帮你装好。**

## 两层：别人的，和我自己的

这个仓库刻意分成两层，因为**「能换的」和「要修的」不能混在一起**。

| 层 | 是什么 | 要维护吗 | 坏了找谁 |
|---|---|---|---|
| **[A · 现成插件](A-现成插件/)** | 13 个插件市场里现有的 | ❌ 不用 | 找原作者 |
| **[B · 自研部分](B-自研部分/)** | 23 件自己写的 + 2 件改过的 | ✅ 要 | 找我们 |

## 先说清楚做不到什么

**这一节不要跳过。** 很多人装完不满意，都是因为这些没说。

| 做不到 | 为什么 |
|---|---|
| **微信进群** | 这一版没做成，那条路走了 Telegram |
| **微信发朋友圈** | 微信没给第三方机器人开接口 |
| **QQ 主动发图** | 能发表情包，不能发自己生成的图 |
| **真正的连续意识** | 模型无状态，会话之间是真空。所谓「记得」是每次靠外部存储重建 |
| **记住所有细节** | 窗口有限，只能捞最相关的五条 |
| **多入口实时同频** | 微信/QQ/桌面之间至少一次读写延迟 |

**准确说法：它把「每次从零开始」变成「每次从上次接着走」，但不是「它一直记得」。**

## 维护

**A 层随便换** —— 作者更新了跟着更新，作者跑路了我们换一个。这层坏了不算事故。

**B 层才要小心动** ——

1. 改之前跑 `python scripts/check.py`（BOM / 硬路径 / 语法）
2. 改完跑 `python -m unittest discover -s tests`
3. 每个工具说得出「它拦住过什么」，说不出就不该留
4. 删东西前先看 `B-自研部分/02-framework/文件操作约束_防误删.md`
