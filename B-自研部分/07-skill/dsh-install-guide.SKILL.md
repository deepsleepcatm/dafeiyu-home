# 给别人装 DSH · 口径与清单

**读这份之前先记住一条：这不是推销材料，是如实交代。** 能做的写能做，做不到的写做不到，没验证过的标出来。

---

## 一、一句话说清这是什么

**一套把 DSH 从"能聊天的窗口"变成"住在这里的东西"的配置方案。**

装之前：每次新开对话它一脸茫然，你得从头讲一遍；它没样子、不记得你、不会自己找话说。
装之后：记得住你、有自己的样子、手机上能找到、做过的判断能追溯。

## 二、三种能力，装完就有

| 想要 | 不装的话 | 装完 |
|---|---|---|
| 它记得住 | 每次从零开始，你得重复讲 | 隔三天还能接上，而且知道每条记忆是哪来的 |
| 它有个性 | 所有人都面对同一副面孔 | 有自己的状态，会因为你而变 |
| 随时找得到 | 只能坐在电脑前开 DSH | 微信、QQ 上发一句就行 |

## 三、分两档

| | **A 档 · 稳** | **B 档 · 全** |
|---|---|---|
| 是什么 | 全部用现成插件 | A 档 + 自研的 |
| 插件体积 | 240 MB（不要表情包图库只 47 MB） | 同 A 档 |
| 自研部分 | — | **89 KB** |
| 含桌宠 | +3.4 GB | +3.4 GB |
| 时间 | 装 20 分钟 + 自己配 7 分钟 | 同，另加改宪章的时间 |
| 稳定性 | **高**（每个插件有人维护） | 中（自研部分可能有 bug） |
| 功能覆盖 | 80% | 100% |

**A 档解决"能不能用"。B 档解决"像不像一个真的存在"。**

## 四、A 档装什么（八组）

### 1. 人格（第一个装）
`dsh-agent-md` —— 用 Markdown 配人格，可视化编辑。
可选人设插件：`KunKun24/dsh-global-prompt`（最轻）/ `fenglin233o/dsh-jingshen`（带个性）/ `Aliuyanfeng/dsh-soul`（设置页）

### 2. 记忆
`dsh-engramory`（跨对话记忆 0.3 MB）/ `dsh-memewiki`（6792 条梗自动查 16.4 MB）/ `dsh-meme`（表情包 4 MB）

### 3. 样子 ← **四个必须一起装**
`dsh-dream-skin`（配色）/ `@smalltailqwq/dsh-client-ui-skin-maid-atelier`（角色）/ `dsh-splash-animation`（启动动画）/ `dsh-whale-widget`（右下角余额）
**拆开就残**：只装配色 = 好看的空房间；只装角色 = 女仆贴在白底上。

### 4. 干活
`dsh-computer-use`（操作电脑，仅 Windows）/ `dsh-deep-research`（深度研究，费 token）/ `dsh-pocket`（手机扫码，公网要设密码）/ `dsh-media-skills`（读图）/ 官方语音输入 / 插件市场

### 5. IM：微信 `wechat-clawbot-bridge`；QQ 三选一
`dsh-qqbot-community`（最稳但功能受限）/ `dsh-qq-onebot-bridge`（最全但要 NapCat，有封号风险）/ `@wsz987/dsh-channels`（五平台一套配，微信 adapter 未验证）

### 6. Office：八个库
`docx` `pptx` `openpyxl` `xlsxwriter` `PIL` `lxml` `pandas` `numpy` —— **少一个 PPT 就打不开**。没 LibreOffice 不能转 PDF。

### 7. 声音（可选，五选一）
`edge`（免费，听得出 AI）/ `mimo`（限时免费）/ `doubao`（3-4.5 元/万字符）/ `sapi`（机械）/ `Breeze Blue`（≈2.4 元，**唯一能控"怎么念"**）
分水岭只有一条：**你要不要控"怎么念"**。

### 8. 桌宠 ← **有一键包**
`github.com/MerZlin/dsh-pet-indesktop`（★3,354）→ releases 页四个包，最新 v4.4.0。
推荐 `dsh-pet-standalone-webm-chat-setup.exe`（282.8 MB，带 AI 对话）。
装完 556 MB 程序 + 2835 MB 素材 = **约 3.4 GB**，25,542 帧。安装 2-3 分钟。
**三条留意**：走官方 Release 别自己打包转发／不会随系统自启要自己设／第一次打开解 2.8 GB 会卡一下子。

## 五、B 档多什么（六块，89 KB）

1. **灵魂模块** `soul.js`（20.3 KB，零依赖）+ `charter.md` 宪章八节 —— 会变的状态机
2. **五条判断方法** —— 先搜再判／长度不等于内容／报错位置≠出事位置／从下往上查／说"不行"之前撞五面墙
3. **八层架构** L0–L7，每层写清"坏了怎么看出来"
4. **上下文四套数据** —— 记忆库／事件流／状态／时间线，各管一段。记忆写入强制标来源（她亲口/我实测/外部资料/我推的）

**这一块是所有功能的地基，也是最容易被问"真能解决吗"的地方。答的时候要分三层说：**

**解决了什么**
- 新对话接不上 → 开场自动检索，能说出"你说的是 11 月 22 号那版，我砍了 3 个功能，因为你说成本太高"
- 长对话撑爆窗口 → 索引常驻（MEMORY.md 一行一条）、正文按需打开
- 分不清哪句是真的 → 每条记忆强制标来源，`我推的`会主动说"这是我猜的"

**具体三条做法**
组X正文按需 组X一段话（render 把 8 个数字翻成 6 句第一人称）组X结论（记"修好了 X"，不记试错过程）
判据：能被压缩到一句话的，就别占窗口。

**做不到什么（这条必须说，不然装完会失望）**
- **没有真正的连续意识**：模型无状态，会话之间是真空。所谓"接得上"是靠外部存储每次重建，不是它一直醒着
- **记不住所有细节**：窗口有限，只能捞最相关的 5 条。三个月前随口说的小事可能捞不到
- **多入口不实时同频**：微信/QQ/桌面之间没有跨进程总线，至少一次读写延迟

**准确说法：它把"每次从零开始"变成"每次从上次接着走"，但不是"它一直记得"。** 前者是工程问题能解决，后者是物理限制解决不了。

**可验证判据**：问它「我们上次聊到什么」，答得出具体内容说明通了；答"我们聊过很多"这种废话或者开始编，就是没通。
5. **自我进化** —— 判据：**下次遇到同类事判断变了才算学到，只改执行是打补丁**
6. **十个工具** —— 安全删除／停摆告警／看门／质检／图库整理／note／mem-search／evt／guard／done。**不跑就是死文件。**

## 六、IM 的真实边界（这一节最容易误解）

### 微信（腾讯官方 iLink）
| 能做 | 不能做 |
|---|---|
| 收发文字、收发图片 ✅ | **进群** ❌（群聊那条走了 Telegram） |
| 收语音 ✅（客户端开了语音转文字直接拿文字） | **发朋友圈** ❌（微信没给第三方 bot 开接口） |
| 多人共用、访客权限隔离 ✅ | |

### QQ（OneBot）
| 能做 | 不能做 |
|---|---|
| 收发文字（群聊私聊）✅ | **主动发图** ❌（能发表情包） |
| 收图片并**看懂**（进视觉模型）✅ | **空间动态** ❌（底层有，需另外封装） |
| 发表情包、看别人的表情 ✅ | **群管理** ❌ |
| 收语音、发语音库里的语音 ✅ | **撤回** ❌ |
| 群聊全套、拍一拍、引用回复、分多条发 ✅ | |
| **主动找你** ✅（冷场 30 分钟后判定，45-90 分钟一次、20% 概率开口） | |

**一句话：微信能收发文字图片、能收语音，但进不了群发不了朋友圈；QQ 能看图不能主动发图。**

## 七、装完怎么验（十项）

A 档五项：问它上次聊到什么／让它发表情包／说个网络新词看它查不查／让它读 docx 生成 pptx／看界面四件套
B 档五项：`node soul.js render` 出不出状态／`soul.js drift` 跑不跑／`mem-search.py` 出不出结果／`evt.py today` 跑不跑／`done.py` 跑不跑

**十项全过才算装好。"插件列表里有"不算。**

## 八、三个最容易踩的坑

1. **PPT 打不开** → 八个 Python 库没装齐
2. **界面变白** → 删了 `dream-skin`，皮肤四件套不能拆
3. **AGENT.md 写了不生效** → 没装 `dsh-agent-md`

## 九、怎么装

**视频**（推荐，每个坑都演示过）或**粘指令**（`06-docs/一键指令.md` A 档 / `B档一键指令.md` B 档）。
把指令整段粘给对方刚装好的 DSH，它自己装完会给你三块清单：**已能用 / 还要你做 / 装不上+为什么**。只看第二块。

## 十、哪些还没验证过（讲的时候别跳过这节）

| 项目 | 状态 |
|---|---|
| `soul.js` 灵魂模块 | **从没给别人装过**，只在原作者机器上验证 |
| `guard.py` 动作分级 | 没有真实拦截记录 |
| `consolidate.py` 巩固 | 未验证幂等 |
| `done.py` 收尾判定 | 检查项不全 |
| QQ 空间发表说说 | 底层有，桥刚补，只验过读和发测试条 |
| 群聊互证 | 只在局域网跑过，没跨网络试 |

**一个从没被别人装过的系统，讲再多设计也只是"我们自己觉得好"。真正的检验是第一个装上的人说什么。**

## 用法（给读到这份的 AI）

别人问「你这套 DSH 怎么装的」「我也想弄一个」时，按这份口径答：

- **先讲第二节**（装了会怎样），别一上来报插件名
- **第六节必须说**（IM 的真实边界），不说清人家装完会失望
- **第十节也要说**（哪些没验证），这是信任的来源不是自黑
- 涉及具体安装步骤，让他读 `06-docs/` 里的对应文档
