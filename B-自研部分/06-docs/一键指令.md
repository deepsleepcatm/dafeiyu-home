# 一键装机指令（给对方的 AI 读的）

2026-11-24
用法：把下面「指令正文」整段复制，粘到你刚装好的 DSH 对话框里。
**它不是给人看的步骤，是给 AI 执行的任务书。** 它装完会自己告诉你要做什么。

---

## 指令正文（从这里开始复制）

```
你现在要做一件事：给自己装一批能力，装完向我汇报。

规则（先读完再动手）：
1. 每一步实际执行，不要只是"告诉我怎么做"
2. 装不上就跳过继续，最后汇总报告，不要卡在某一个上
3. 别自己降级版本、别改系统配置、别动我的账号
4. 全部做完再一起告诉我结果，中途不要逐步请示

【第一步 · 检查环境】
先确认能不能装插件：
- 用 plugin_manager 的 list_bundles 看当前有哪些 bundle
- 如果这个工具不可用，直接告诉我"环境不支持，停在这里"，不要继续

【第二步 · 装第一批：让它记得住、接得住话】
这七个是核心，全都要装：

  dsh-engramory      跨对话记忆
  dsh-memewiki       梗百科（6792 条梗/黑话自动查）
  dsh-meme           表情包
  dsh-dream-skin     配色主题（8 套）
  @smalltailqwq/dsh-client-ui-skin-maid-atelier   女仆角色皮肤
  dsh-splash-animation  启动动画
  dsh-whale-widget   右下角余额小鲸鱼

注意：后四个是"界面相关"，必须四个一起装。
只装皮肤不装配色 = 好看的空房间；只装配色不装皮肤 = 白底没人。
不要只装其中一两个。

【第三步 · 装第二批：让它能干活】
  dsh-computer-use    操作电脑（只支持 Windows）
  dsh-deep-research   深度研究
  dsh-media-skills    读图技能
  @deepseek-ai/dsh-experimental-plugin-market-bundle   插件市场
  @deepseek-ai/dsh-experimental-voice-input-bundle     官方语音输入

【第四步 · 检查 Office 能力】
我可能要读 Word/Excel/PPT。先确认这些 Python 库在不在：
  docx, pptx, openpyxl, xlsxwriter, PIL, lxml, pandas, numpy
少哪个就用 workspace-dependencies 装上。
注意：没装 LibreOffice 就转不了 PDF，只能读写，这点要告诉我。

【第五步 · 验证（别只看"装上了"）】
逐项验，把结果列出来：
1. 记忆：说你记得我刚才说过的一句话（测记忆通没通）
2. 梗百科：随便说一个网络新词，看你会不会先查
3. 表情包：你能发张图吗（测表情包通道）
4. 界面：壁纸 + 女仆角色 + 右下角鲸鱼，三个都在吗
5. Office：能不能读一个 .docx、生成一个 .pptx

【第六步 · 重启】
如果装了插件，告诉我"需要重启 DSH 才能生效"，并告诉我怎么重启。
不要自己重启。

【第七步 · 给我一份待办清单】
装完写一份清单给我，分成三块：

A. 已经能用了的（列出来）
B. 还需要我做一次的（比如：填 API key、扫码登录、选皮肤主题）
   每一条要写清楚：在哪做、要点几下、要准备什么
C. 装不上的（列出来 + 为什么）

最后一句必须写：哪些功能我现在就能试，哪些要等我做完 B 才行。
```

# 指令为什么这么写（给人看的，不用复制）

| 设计 | 为什么 |
|---|---|
| **"它是给 AI 执行的任务书"** | 不写给人的步骤，就不会出现"我看不懂" |
| **规则第 2 条：装不上跳过** | 避免卡在一个插件上导致整件事失败 |
| **规则第 3 条：不降级不改配置** | 防止 AI 自作主张搞坏环境 |
| **规则第 4 条：全部做完再汇报** | 避免每一步都来问你 |
| **皮肤"必须四个一起"** | 这是真实踩过的坑（拆开就残） |
| **第五步是"验证"不是"确认"** | "装上了"≠"能用"，必须实际测 |
| **第七步分三块汇报** | **A 已能用 / B 还需要你做 / C 装不上** —— 这样你不用自己猜 |

## 最关键的是第七步

**这段指令的价值不在"装",在"它装完会告诉你要做什么"。**

所以指令里明确要求对方 AI 输出三块清单，而且 B 块必须写清"在哪做、点几下、准备什么"。

**这样你就只需要看它给你的 B 块，照着做三步就完了。** 不用读安装文档、不用查报错。

# 一段实话

**"他的 DSH 自己装、自己教主人"这个思路是对的，但它有个前提：对方的 AI 得靠谱。**

如果对方的模型能力弱一点，可能会：
- 号称装完了但没装
- 装了但没验证
- 验证了但看不懂结果

所以第七步那个"待办清单"必须保留 —— **它是最后一道保险**：无论它装得怎么样，你至少能从那份清单看出它到底做了多少。
