# 一、这是什么

**一套把 DSH（DeepSeek Harness）从"能聊天的窗口"变成"住在这里的东西"的配置方案。**

装之前：每次新开对话，它一脸茫然，你得从头讲一遍。它没有样子、不记得你、不会自己找话说。
装之后：它记得住你、有自己的样子、手机上能找到、会自己找视频看、做过的判断能追溯。

**三种能力，装完就有了：**

| 想要 | 不装的话 | 装完 |
|---|---|---|
| 它记得住 | 每次从零开始，你得重复讲 | 隔三天还能接上，而且知道每条记忆是哪来的 |
| 它有个性 | 所有人都面对同一副面孔 | 有自己的状态，会因为你而变 |
| 随时找得到 | 只能坐在电脑前开 DSH | 微信、QQ 上发一句就行 |

# 四、B 档：多什么（全部只有 89 KB）

**值钱的是方法，不是体积。**

## 4.1 灵魂模块（`soul.js` + 宪章）

会变的状态机：心情 4 维（好受/激动/安全/连着）+ 关系 4 维（熟悉/信任/依恋/边界），接 13 种事件。20.3 KB，零依赖。
配 `charter.md` 宪章 8 节：我是谁 / 什么排第一 / 撞五面墙 / 怎么学 / 冲突怎么选 / 我不是什么 / 我怕什么 / 何时改。

**验证到哪**：跑了 82 条记录状态真在变；负面事件默认"只记不生效"；drift 检查实测（换说法立场没变 → 0.65 判稳；立场反转 → 0.09 判漂）；`install.py` 装完自动生效。**但从没给别人装过。**

## 4.2 五条判断方法

```
组X              不拿旧记忆当依据
组X于内容         读完再判；说不出里面有什么 = 没读
组X ≠ 出事位置    先问"这是什么层的问题"
组X查            别从最上层开始猜
组X"之前撞五面墙    换路径 / 换层次 / 换工具 / 换角度 / 问人
```

## 4.3 八层架构（整套东西的骨架）

| 层 | 坏了怎么看出来 |
|---|---|
| L0 硬件与系统 | 所有命令都"能跑但结果怪" → 先怀疑策略 |
| L1 运行时 | 报错看不懂 → 先问"用的哪个解释器" |
| L2 应用本体 | 插件装了不生效 → 先查版本兼容 |
| L3 常驻服务 | 服务"在"但没反应 → 查活跃度，不是进程 |
| L4 外部依赖 | 连接通但没数据 → 查上游自己日志 |
| L5 数据层 | 记不住事/文件损坏 → 查写入路径和编码 |
| L6 业务层 | 某个成员不说话 → 查会话和唤醒记录 |
| L7 判据层 | **不知道发生了什么** → 这一层本身就是答案 |

**真实案例**：`numpy._core` 找不到（报在 L5，根因 L1）／Whisper 预热失败（根因是四天前的补丁，跨 4 天）／`exit code -1`（是管道被关，不是命令失败）／"丢了两个组"（看着像 L6，其实 L1 的正则只取第一个匹配）。

## 4.4 上下文（跨会话四套数据）

**这一节是 B 档最核心的部分**，因为它是所有其他功能的地基：一个记不住事的 AI，状态、判断、进化都无从谈起。

| 数据 | 管什么 |
|---|---|
| 记忆库 | 长期事实：你是谁、什么话别说、约定、教训 |
| 事件流 | 做过什么：决策/动作/失败/交接 |
| 状态 | 我现在什么样：心情、关系 |
| 时间线 | 怎么变成这样的：可重放 |

**开场三件事**：读状态 → 读交接 → **用你第一句话去检索**（不是把记忆全塞进去，是捞最相关的 5 条）。
**记忆写入强制标来源**：她亲口 / 我实测 / 外部资料 / 我推的。**没有来源写不进去。**

### 上下文怎么真的解决问题（以及解决不了什么）

这个要说准，不然装完会失望。

**它解决的三个具体问题：**

| 问题 | 不装会怎样 | 装完 |
|---|---|---|
| 新对话接不上 | 每次从头讲，讲完它还是抓不准你想要哪个方向 | 开场自动检索，能说出"你说的是 11 月 22 号那版，我砍了 3 个功能，因为你说成本太高" |
| 长对话撑爆窗口 | 聊到几十轮开始丢前面的内容，它突然忘了你在干什么 | 索引常驻、正文按需：`MEMORY.md` 一行一条，只有看起来相关的才打开 |
| 分不清哪句是真的 | 它把自己猜的说得像查过的一样 | 每条记忆强制标来源，`我推的`会主动告诉你"这是我猜的" |

**具体三条做法（不然"按需读"是空话）：**

```
组X，正文按需 —— 索引一行一条占窗口，细节按需打开
组X一段话   —— render 把 8 个数字翻成 6 句第一人称，不倒 JSON
组X结论     —— 记"修好了 X"，不记"试了 A 失败、B 失败、C 成功"
```

**判据一句话：能被压缩到一句话的，就别占窗口。**

**它做不到的三件事（这条必须说）：**

| 做不到 | 为什么 |
|---|---|
| **真正的连续意识** | 模型是无状态的，会话与会话之间是真空。所谓"接得上"，是靠外部存储每次重建，不是它一直醒着 |
| **记得住所有细节** | 窗口就那么大，只能捞"最相关的 5 条"。你要问一个三个月前随口说过的小事，可能捞不到 |
| **多入口实时同频** | 微信/QQ/桌面/手机几个入口之间没有跨进程总线，至少有"一次读写"的延迟。A 口刚说的话，B 口不会瞬间知道 |

**所以准确说法是：它把"每次从零开始"变成"每次从上次接着走"，但不是"它一直记得"。** 前者是工程问题，能解决；后者是物理限制，解决不了。

**一个可验证的判据**：装完问它「我们上次聊到什么」。答得出具体内容（不是"我们聊过很多"这种废话），说明通了；答不出或者开始编，说明没通。

## 4.5 自我进化 & 自我变强

> **下次遇到同类的事，判断变了，才算学到。只改执行是打补丁。**

- **打补丁**：这次忘了验证 → 加一步验证
- **学到**：问"我为什么觉得不用验证"，发现是"我以为改的东西很简单" → **改那个"以为"**

## 4.6 重复学习（巩固）

`consolidate.py`：补字段、算权重、标过期。**不跑它记忆库会越攒越乱**，检索越来越不准。

**一个真实记录**：有条规矩写进记忆库（importance 9），同一轮又犯了，因为**记的内容本身是错的**（把"用某个写法不会加 BOM"当规矩，一天犯五次，第五次是修复脚本自己犯的）。
> **"我记下了"和"我不会再犯"之间，差的是"这条本身对不对"。**

## 4.7 自研工具链（十个）

| 工具 | 它拦住过什么 |
|---|---|
| `安全删除.py` | 按时间戳删会话，正在用的也被删了 |
| `停摆告警.py` | 服务卡住了（判据是"消息追到哪"，不是"进程在不在"） |
| `看门.py` | 七个服务的输出全进黑洞，一条日志都没有 |
| `质检.py` | 插件指向空环境，配了但跑不了 |
| `图库整理.py` | 664 张图里 338 张完全重复，白占 194 MB |
| `note.py` | 记忆写入不标来源，事后分不清哪句是真的 |
| `mem-search.py` | 跨对话检索（本地向量 + 关键词） |
| `evt.py` | 做了事没记，等于没做 |
| `guard.py` | 动作风险分级 R0-R3 |
| `done.py` | "我觉得做完了"不算数，要机器判 |

**这一组不是装上就生效的。** 靠平时真用，不用就是硬盘上的死文件。
