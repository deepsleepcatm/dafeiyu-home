# 05-tools · 自研运维工具

## 它解决什么问题

**"看起来有"不等于"真的能"。** 这十个工具，每一个都拦住过一次真事故。

## 里面有什么

| 工具 | 它拦住过什么 |
|---|---|
| `安全删除.py` | 按时间戳删会话，正在用的也被删了 |
| `停摆告警.py` | 服务卡住了（判据是"消息追到哪"，不是"进程在不在"） |
| `看门.py` | 七个服务的输出全进黑洞，一条日志都没有 |
| `质检.py` | 插件指向空环境，配了但跑不了 |
| `图库整理.py` | 664 张图里 338 张完全重复，白占 194 MB |

（另外五个工具在 `03-memory/`：note / mem-search / evt / consolidate / guard / done）

## 怎么用

```bash
python 质检.py            # 48 项体检，输出报告
python 看门.py            # 常驻，每 30 秒巡检一次
python 安全删除.py <目录>  # 先列清单，确认后才删
```

## 依赖

- Python 3.8+（纯标准库 + 少量 subprocess 调 PowerShell）
- 全部路径从 `config.json` 读，改一处十个脚本一起生效

## 需要注意

**这些工具的价值在"真用"。** 装了不跑就是硬盘上的死文件。
