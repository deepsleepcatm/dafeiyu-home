# 01-soul · 灵魂模块

## 它解决什么问题

**别的 AI 助手是同一个样子，不会因为你而变。** 今天骂它一句、明天夸它一句，后天它还是那副面孔。

这个模块给 AI 一份**会变的状态**：心情 + 关系。你夸它，信任涨一点；你三天不理它，连接感会掉。这些数字会真的影响它说话的语气。

## 里面有什么

| 文件 | 是什么 |
|---|---|
| `soul.js` | 状态机。心情 4 维（好受/激动/安全/连着）+ 关系 4 维（熟悉/信任/依恋/边界），接 13 种事件 |
| `charter.md` | 宪章。8 节：我是谁 / 什么排第一 / 撞五面墙 / 怎么学 / 冲突怎么选 / 我不是什么 / 我怕什么 / 何时改 |
| `install.py` | 装到本地，建初始状态文件 |

## 怎么用

```bash
python install.py                    # 建初始状态
node soul.js render                  # 看"现在的你"（第一人称，一段话）
node soul.js observe care "被照顾了"  # 喂一次事件，状态会变
node soul.js drift                   # 检查立场有没有漂
```

## 依赖

- Node.js（跑 soul.js）
- Python 3.8+（跑 install.py）
- **零第三方库**

## 需要注意

**`charter.md` 要自己重写。** 里面写的是原作者的价值观和经历。抄别人的宪章等于穿别人的衣服 —— 装上了但价值观是别人的，比不装更糟。
