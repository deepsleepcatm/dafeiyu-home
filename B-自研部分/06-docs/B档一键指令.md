# B 档一键指令（给对方的 AI 读的）

2026-11-24
用法：把下面「指令正文」整段复制，粘到你刚装好的 DSH 对话框里。
**它是给 AI 执行的任务书，不是给人看的步骤。** 它装完会自己告诉你要做什么。

**B 档 = A 档 + 我们自研的。** 多出来的部分是：一个会变的状态机、五条判断方法、八层架构、跨会话四套数据、自我进化、重复学习。

---

## 指令正文（从这里开始复制）

```
你现在要做一件事：给自己装一批能力，包括几个自研模块。装完向我汇报。

规则（先读完再动手）：
1. 每一步实际执行，不要只是"告诉我怎么做"
2. 装不上就跳过继续，最后汇总报告，不要卡在某一个上
3. 别自己降级版本、别改系统配置、别动我的账号
4. 全部做完再一起告诉我结果，中途不要逐步请示
5. 自研模块是开源代码，来源会在下面写明。装之前先读一遍，有不懂的先问我

【第一步 · 检查环境】
1. 用 plugin_manager 的 list_bundles 看当前有哪些 bundle。如果这个工具不可用，告诉我"环境不支持"，停在这里
2. 报告你的 Python 版本（python --version）和解释器绝对路径
   —— 这一步很重要：后面装的自研脚本对 Python 版本有要求

【第二步 · 先装 A 档（现成插件）】
这七个是核心，全都要装：

  dsh-engramory      跨对话记忆
  dsh-memewiki       梗百科（6792 条梗/黑话自动查）
  dsh-meme           表情包
  dsh-dream-skin     配色主题（8 套）
  @smalltailqwq/dsh-client-ui-skin-maid-atelier   女仆角色皮肤
  dsh-splash-animation  启动动画
  dsh-whale-widget   右下角余额小鲸鱼

注意：后四个是"界面相关"，必须四个一起装。
只装皮肤不装配色 = 好看的空房间；只装配色不装皮肤 = 白底没人。不要只装其中一两个。

【第三步 · 再装这两批（能干活）】
  dsh-computer-use    操作电脑（只支持 Windows）
  dsh-deep-research   深度研究
  dsh-media-skills    读图技能
  @deepseek-ai/dsh-experimental-plugin-market-bundle   插件市场
  @deepseek-ai/dsh-experimental-voice-input-bundle     官方语音输入

【第四步 · 检查 Office 能力】
我可能要读 Word/Excel/PPT。先确认这些 Python 库能不能 import：
  docx, pptx, openpyxl, xlsxwriter, PIL, lxml, pandas, numpy
少哪个就装哪个。
注意：没装 LibreOffice 就转不了 PDF，只能读写，这点要告诉我。

【第五步 · 装自研模块（B 档的核心）】
自研部分是开源的，来自这两个仓库：
  soul      → https://github.com/<作者>/dsh-soul
  framework → https://github.com/<作者>/dsh-framework

装法：把仓库 clone 或下载下来，按下面四件事做。

组X（会变的状态）
   把 soul.js、charter.md、install.py 放到一个你选定的目录（建议 ~/.dsh/soul/）
   跑一次 install.py —— 它会建初始状态文件
   然后跑 node soul.js render，应该输出一段"现在的你：……"的第一人称状态
   ⚠️ charter.md 是宪章，里面写的是原作者的价值观和经历。
      你要提醒我改成我自己的：抄别人的宪章等于穿别人的衣服。

组X（六个脚本）
   note.py / mem-search.py / evt.py / consolidate.py / guard.py / done.py
   放到 ~/.dsh/mem-tools/
   先 cp config.example.json config.json，按实际情况改路径
   跑一次 python config.py —— 它会自检，告诉你读到了什么、哪些目录还缺

组X + 八层架构（文档）
   这是两份要读的东西，不是要装的东西：
   - 五条判断方法：先搜再判 / 长度不等于内容 / 报错位置≠出事位置 / 从下往上查 / 说"不行"之前撞五面墙
   - 八层架构 L0-L7：每层写清"坏了怎么看出来"
   把这两份放进你的知识目录，并且在以后排障时按 L0→L7 的顺序查。

组X（可选，只有需要多会话协同时才装）
   group-chat/ 里有 server.py + chat-bridge.mjs + trace.mjs
   装之前先问我：要不要多开几个会话一起干活。不要就跳过。

【第六步 · 验证（别只看"装上了"）】
逐项验，把结果列出来：

A 档部分：
1. 记忆：说你记得我刚才说过的一句话
2. 梗百科：随便说一个网络新词，看你会不会先查
3. 表情包：你能发张图吗
4. 界面：壁纸 + 女仆角色 + 右下角鲸鱼，三个都在吗
5. Office：能不能读一个 .docx、生成一个 .pptx

B 档部分：
6. 状态：node soul.js render 能出"现在的你：……"吗
7. 漂移：node soul.js drift 能跑吗，结果是什么
8. 检索：mem-search.py query "随便一个词" 3 能出结果吗
9. 事件：evt.py today 能跑吗（应该是 0 条，正常）
10. 收尾：done.py 能跑吗

**十项全过才算装好。"插件列表里有"不算。**

【第七步 · 重启】
如果装了插件，告诉我"需要重启 DSH 才能生效"，并告诉我怎么重启。不要自己重启。

【第八步 · 给我一份待办清单】
装完写一份清单给我，分成三块：

A. 已经能用了的（列出来）
B. 还需要我做一次的
   每一条写清楚：在哪做、要点几下、要准备什么
   特别注意这几项：
   - 宪章要我自己重写（原作者的不能直接用）
   - 如果装了群聊，组名要我自己定
   - 任何需要 API key 的地方
C. 装不上的（列出来 + 为什么）

最后一句必须写：哪些功能我现在就能试，哪些要等我做完 B 才行。
```

# 为什么比 A 档多三步（给人看的，不用复制）

| 多出来 | 为什么必须这么写 |
|---|---|
| **第三步要先装 A 档** | B 档是 A 档的超集。先装 A 档，后面崩了至少还有能用的东西 |
| **第五步分四件事** | 自研部分是四块不同的东西（状态机 / 记忆工具 / 文档 / 群聊），混在一起装必乱 |
| **宪章要提醒对方改** | 这是唯一一处会"装错"的地方 —— 装上了但价值观是别人的，比不装更糟 |
| **第八步 B 块特别点名三项** | 宪章重写、群聊组名、API key —— 这三样是"必须用户自己动手"的，AI 替不了 |
| **验证从九项变十项** | 多了一项 `done.py`（收尾机器判定），因为 B 档多了一个"我觉得做完了不算数"的规矩 |

# 一个提醒

**自研部分的价值不在"装上"，在"平常真用"。**
那十个工具（note / evt / mem-search / consolidate / guard / done / 安全删除 / 停摆告警 / 看门 / 质检）**不跑就是硬盘上的死文件**。
视频里会演示一遍每天怎么用，但**没人能替你坚持**。

# 和 A 档的关系

- **A 档**：装完就能用，80% 功能，每个插件都有作者维护
- **B 档**：装完还要你学一套方法（判断五条 + 八层架构），100% 功能，**自研部分可能有 bug**
- **选哪个看你要什么**：只想有个能聊能画图的助手 → A 档够了。想让它的判断随时间长出来 → B 档
