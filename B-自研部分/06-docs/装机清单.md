# 一、这份清单是什么

**是一份实测过、标了代价的安装指引。** 每一样东西我们都装过、用过、踩过坑，坑写在它旁边。

- **能保证的**：清单里每一条，都在我们机器上真的跑通过
- **不能保证的**：你的环境不一样，可能遇到我们没遇到的
- **遇到问题去哪问**：现成插件找插件作者（每样下面都写了包名，可以去 npm / GitHub 提 issue）；自研部分在仓库提 issue，我们看到会处理
- **装不上或报错看不懂**：照最后一节「排查表」一条条对，那里面是今天全部真实报错的解法

**动手前先备份一次。** 换插件、改配置都可能让原来的设置失效，备份两分钟能省几小时。

## 3.5 接进 IM

**微信**：`wechat-clawbot-bridge`（我们打包的）
走腾讯官方 iLink（微信 ClawBot），不是野路子。要扫码，登录态会过期要重扫。

**QQ**：三选一

| 方案 | 效果 | 代价 |
|---|---|---|
| `dsh-qqbot-community` | 官方机器人，最稳 | **功能受限**（无私聊、无群管、无撤回），要官方审核 |
| `dsh-qq-onebot-bridge` | 功能全 | 要另装 NapCat，**有封号风险** |
| `@wsz987/dsh-channels` | 五个平台一套配 | **它的微信 adapter 自己标着「真实环境未验证」** |

## 3.6 Office 能力（要装八个库）

**要八个 Python 库**：`docx` `pptx` `openpyxl` `xlsxwriter` `PIL` `lxml` `pandas` `numpy`
**少一个 PPT 就打不开。** 让 AI 跑一次 `workspace-dependencies` 装齐。
**没 LibreOffice 就不能转 PDF**，只能读写。

## 3.7 说话的声音（可选）

| 后端 | 像真人 | 能演（控语气/停顿） | 钱 |
|---|---|---|---|
| `edge`（默认） | 自然但听得出 AI | ❌ 只有语速 | **免费** |
| `mimo`（小米·冰糖） | 很像 | ❌ | **限时免费**（要 key） |
| `doubao`（豆包·佩奇） | 很像 | ❌ | 3～4.5 元/万字符 |
| `sapi`（Windows） | 机械 | ❌ | 免费 |
| **`Breeze Blue`** | **很像，能带情绪** | ✅ **instructions 能控表演** | **≈2.4 元/万字符**（有免费档） |

**分水岭就一条：你要不要控"怎么念"。**

**便宜的三个各有一个坑**：
1. `edge` **微软没明确授权商用**，自己用可以，做成产品卖要换；单日别超 5 万次
2. `mimo` 是"限时免费"，不是永久
3. key 在 config.json 里是**明文**

# 四、B 档多出来的（自研）

**全部只有 89 KB。** 值钱的是方法，不是体积。

## 4.1 灵魂模块 `soul.js`

**效果**：会变的状态机。存心情（好受/激动/安全/连着）+ 关系（熟悉/信任/依恋/边界）。
**体积**：14.6 KB，零依赖。

**验证到哪一步**：
- ✅ 跑了 82 条记录，状态真在变
- ✅ 负面事件默认「只记不生效」（怕变冷可以这么设）
- ✅ 行为画像 + drift 检查（实测：换说法但立场没变 → 0.65 判稳；立场反过来 → 0.09 判漂）
- ❌ **从没给别人装过**
- ❌ **还没做成"装完自动生效"**

## 4.3 宪章

**是什么**：一份"我是谁"的声明。写「什么排第一」「冲突时怎么选」「我怕什么」。
**效果**：决定该优化哪些维度，让选择在冲突时自动偏向一边。
**体积**：8.2 KB。
**代价**：**每个人得自己写**。抄别人的宪章等于穿别人的衣服。

# 六、三个最容易踩的坑

1. **PPT 打不开** → 八个 Python 库没装齐
2. **界面变白** → 删了 `dream-skin`，底色层没了；皮肤四件套不能拆
3. **AGENT.md 写了不生效** → 没装 `dsh-agent-md`，光有文件不管用
