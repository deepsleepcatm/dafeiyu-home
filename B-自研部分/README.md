# B · 自研部分（我们要维护的）

**这一层每一个都要自己修。** 这里没有第三方依赖，全是自己写的。

## 七个模块

| 目录 | 是什么 | 要维护吗 |
|---|---|---|
| `01-soul/` | 灵魂模块：状态机 + 宪章 | 要，状态机逻辑会改 |
| `02-framework/` | 八层架构 + 文件操作约束（文档） | 要，跟着踩坑更新 |
| `03-memory/` | 六个记忆工具 | 要，最常改 |
| `04-im/` | 群聊桥 | 要，最容易出 bug |
| `05-tools/` | 五个运维工具 | 要，每次事故后加一条 |
| `06-docs/` | 安装文档 | 要，每次改流程就要改 |
| `07-skill/` | 给对方的 AI 读的口径 | 要，跟文档同步 |

## 维护规矩

1. **改之前先跑 `python ../scripts/check.py`**（BOM / 硬路径 / 语法）
2. **改完跑 `python -m unittest discover -s ../tests`**
3. **每个工具的 README 里写清「它拦住过什么」** —— 说不出就不该留
4. **删东西前先看 `02-framework/文件操作约束_防误删.md`**

## 为什么单独一层

因为这一层的东西**从没被别人装过**，出 bug 是常态。
把它单独隔开，别人一看就知道：A 层坏了找作者，B 层坏了找我们。
